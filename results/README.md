# Makueni County Tree Cover & Land Cover Monitoring — Results

## Overview

The 2026 assessment produced county-scale tree-cover and land-cover information for Makueni County using remote sensing and GIS-based analysis.

The pilot achieved **over 80% accuracy**, with the following reported mapping accuracies:

| Assessment         |  Accuracy |
| ------------------ | --------: |
| Tree-cover mapping | **84.4%** |
| Land-cover mapping | **81.1%** |

## Key Findings

The 2026 assessment estimated:

| Indicator    | 2026 Estimate |
| ------------ | ------------: |
| Tree cover   |    **14.72%** |
| Forest cover |     **6.83%** |

These results provide a spatial basis for understanding the distribution of tree cover and land-cover classes across Makueni County.
